# Alexander Milambo — Portfolio

A static, dependency-free portfolio site (plain HTML/CSS/JS, hash-based routing).

## Structure
- `index.html` — the whole site
- `assets/img/` — photographs and logo mask
- `vercel.json` — caching and security headers

## Deploy
**Vercel:** import this GitHub repo. Framework preset: *Other*. Build command: none. Output directory: leave blank (root).

**GitHub Pages (alternative):** Settings → Pages → Deploy from branch → `main` / root.

## Enquiry form
`ENDPOINT` in `index.html` is empty, so enquiries open as a pre-filled email. Set it to a form backend URL (e.g. Formspree) to send directly.
